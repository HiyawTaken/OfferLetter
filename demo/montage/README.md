# Montage source

The final video is ../offerletter-demo.mp4. This folder retains the scene, 3D renderer, beat grid, cue sheet and export verification. It is source documentation, not a standalone playable bundle: local clip-N.mp4 files and generated narration are kept in the editor workspace. The soundtrack must be obtained from its original source under the license in ../CREDITS.md. The source never contains real user profile data.
